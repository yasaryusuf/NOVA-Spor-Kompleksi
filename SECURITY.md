# Güvenlik ve mahremiyet notları

Bu GitHub deposunda **sadece proje kaynak kodu, örnek görseller ve teknik belgeler** bulunur.

## Kesinlikle paylaşılmaması gerekenler

- `wp-config.php` ve yerel WordPress kurulumunun tamamı
- MySQL/phpMyAdmin kaynaklı `.sql` yedekleri (gerçek kullanıcı bilgileri içerebilir)
- SMTP parolaları, Gmail uygulama parolaları, API anahtarları ve `.env` dosyaları
- Gerçek üye veya PT hesaplarının parola, telefon ve e-posta listeleri
- Üçüncü tarafların kişisel verileri

Ödev için SQL ve WordPress XML çıktısı isteniyorsa, bunları yalnızca öğretim elemanının **özel ödev teslim kanalı** üzerinden, gerektiğinde kişisel bilgileri temizleyerek iletin. XML çıktısı da kullanıcı e-postaları veya başka kişisel veriler içerebilir.

## Sistem sınırları

PT başvuruları yönetici onayı gerektirir. Başvuru işlemleri rezervasyon veya ödeme yerine geçmez. Gerçek yayın öncesi HTTPS, uygun izinler, WordPress/eklenti güncellemeleri, KVKK metinleri ve güvenlik testleri gereklidir.

Güvenlik açığı bildirimi için herkese açık issue üzerinden parola, anahtar veya kişisel veri paylaşmayın.
